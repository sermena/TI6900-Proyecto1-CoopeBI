# analytics

Libros de **Tableau** conectados al Data Warehouse.

- `tableau/` — un libro por perfil de usuario o uno con tres paneles:
  - Gerencia General (visión global de cartera, colocación e ingresos)
  - Gerencia de Créditos y Cobros (morosidad, rangos de atraso, canales de pago)
  - Jefes de Agencia (desempeño por sucursal, productos y segmentos)

Guardar como `.twbx` (empaquetado) para la entrega final, de modo que se abra sin conexión.
