# data

- `raw/` — datos fuente tal como se obtienen (CSV o exportaciones de la base transaccional). No se modifican a mano.
- `processed/` — salidas intermedias del ETL o archivos de validación.

Convención: `<entidad>_<AAAAMMDD>.csv` (ej. `creditos_20261001.csv`).
Archivos de más de 50 MB no se suben al repositorio; se comparten por el drive del grupo y se anota aquí el enlace.
